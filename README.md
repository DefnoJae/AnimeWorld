# WatchAnimeWorld Extension

Provider for WatchAnimeWorld (Hindi/Multi-Audio Anime) for Seanime.

## Features
- Search anime on WatchAnimeWorld
- Extract episodes
- Extract AbyssPlayer / Hydrax video sources for all available languages (Hindi, Tamil, Telugu, Malayalam, Bengali, English, Japanese).

## Installation
Add this extension to Seanime via the Extensions tab.

## Fixes in 1.0.3
- Improved episode-number parsing.
- Validates player responses.
- Uses supported Seanime video source types.
- Sends player Referer/Origin headers.
- Prevents wrong-language fallback.
